# Calls API

`CrowdMeasureCalls.install(...)` registers the optional calls runtime and schedules or starts nothing.

`CallSamplingClient` exposes cellular and generic VoIP toggles, explicit activation, requirements/status flows, session and sample history, independent call uploads, export, and deletion.

`CallStore`, `CallUploader`, and `CallInstallationIdProvider` are integration contracts for existing storage and backend identity.

All mutating operations return `CallSamplingResult`.
